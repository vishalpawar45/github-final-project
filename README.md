# Simple Interest Calculator

A calculator that calculates simple interest given principal, annual rate of interest and time period in years.

## Description
This script calculates simple interest based on user input. It prompts the user for the principal amount, interest rate, and time duration, and then computes the resulting simple interest.

```
Input:
   p, principal amount
   t, time period in years
   r, annual rate of interest
Output:
   simple interest = p*t*r
```
